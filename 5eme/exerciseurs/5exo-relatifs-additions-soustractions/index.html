    Bravo ! Les bases sont comprises, n’hésite pas à retravailler les exercices qui te semblent délicats dans des séries de 10 questions.

    Écris ton résultat avec le signe − s’il est négatif, et une virgule pour un nombre décimal (par exemple −3,5). Les 10 questions d’une série sont réparties équitablement entre les types cochés. Option « Écriture simplifiée » : toutes les questions sont écrites sans parenthèses (la soustraction d’un nombre négatif n’est pas concernée) (−7 + 4 − 2 au lieu de (−7) + (+4) − (+2)), et, pour les additions, le premier nombre est négatif. Un mélange n’est jamais composé uniquement de nombres positifs additionnés. Option « Nombres décimaux » : tous les nombres ont un seul chiffre après la virgule. Mode progression : une étape par type de calcul, dans l’ordre ; une question ratée est suivie d’une autre du même type, jusqu’à la réussite. Chaque question n’a qu’un essai ; « Corriger sans valider » affiche la correction sans compter la question, et une autre du même type est posée.
