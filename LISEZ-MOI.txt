SITE D'EXERCICES DE MATHÉMATIQUES : MODE D'EMPLOI
==================================================

CONTENU DU DOSSIER
  index.html        Page d'accueil : le catalogue (ne pas modifier pour ajouter un exercice).
  exercices.js      La liste des exercices et les réglages. C'est le fichier à modifier.
  exercices/        Un sous-dossier par exerciseur, avec son fichier index.html.
  LISEZ-MOI.txt     Ce fichier.

POUR TESTER SUR VOTRE ORDINATEUR
  Ouvrez index.html dans un navigateur (double-clic). Aucune installation n'est nécessaire.
  Après une modification, rechargez la page avec F5.

AJOUTER UN NOUVEL EXERCICE EN 3 ÉTAPES
  1. Créez un sous-dossier dans « exercices », avec un nom court, sans espace ni accent
     (par exemple « fractions-addition »), et placez-y le fichier de l'exerciseur sous le nom
     index.html.
  2. Dans exercices.js, copiez le modèle donné en commentaire et remplissez-le :
     titre, description, niveaux, thèmes, format, url.
     L'url est le chemin du fichier, par exemple : "exercices/fractions-addition/index.html".
  3. Rechargez index.html : l'exercice apparaît dans le catalogue, avec ses filtres.
  Pour permettre le retour au catalogue, l'exerciseur peut contenir le lien :
     <a href="../../index.html">← Tous les exercices</a>

CRÉER UN NIVEAU OU UN THÈME
  Ajoutez son nom dans SITE.niveaux ou SITE.themes (dans exercices.js), à la place voulue,
  puis utilisez-le dans un exercice. Il faut écrire le nom exactement de la même façon
  (majuscules et accents compris). Seuls les niveaux et thèmes utilisés par au moins un
  exercice sont affichés. Au-delà d'une douzaine de thèmes, les boutons deviennent longs :
  il faudra alors regrouper les thèmes.

MASQUER UN EXERCICE EN COURS DE PRÉPARATION
  Ajoutez   brouillon: true   dans sa fiche. Il n'apparaît plus, sauf si vous ajoutez
  ?brouillons à l'adresse de la page (pour vous, avant de le publier).

PARTAGER UN CATALOGUE DÉJÀ FILTRÉ
  Choisissez un niveau et un thème : l'adresse de la page change, par exemple
  .../index.html?niveau=4e&theme=Fractions . Copiez-la pour donner ce lien à vos élèves.

EN CAS DE PROBLÈME
  • Un cadre rouge en haut de la page indique ce qui ne va pas dans exercices.js
    (champ manquant, niveau ou thème non déclaré, adresse en double...).
  • Si la liste est vide ou si le cadre mentionne une erreur de syntaxe : appuyez sur F12,
    onglet « Console », la ligne fautive est indiquée. Cause fréquente : une virgule, un
    guillemet ou un crochet oublié.
  • Éditez ces fichiers dans un éditeur de texte en UTF-8 (Notepad++ : menu Encodage).
  • Faites une copie du dossier avant de modifier.

METTRE EN LIGNE (GitHub Pages)
  Déposez le contenu de ce dossier dans le dépôt GitHub, en conservant les sous-dossiers
  (« Add file » puis « Upload files » ; si les sous-dossiers ne sont pas conservés par
  votre navigateur, utilisez GitHub Desktop). Le fichier index.html à la racine du dépôt
  remplace alors l'ancien : le lien déjà donné aux élèves affichera le catalogue au lieu
  de l'exerciseur. Le nouveau lien direct de l'exerciseur est :
     .../exercices/calcul-relatifs-fractions-puissances/index.html
